# 💸 Expense Tracker (Python CLI)

## 📌 Overview

This is a simple and user-friendly **Expense Tracker** built using Python.
It helps users manage their daily expenses by allowing them to add, view, and calculate total spending.

🚀 This project was developed as part of my **Internship Task** to demonstrate Python programming skills.



## ✨ Features

* ➕ Add new expenses (amount, category, description)
* 📋 View all saved expenses
* 💰 Calculate total expenses
* 💾 Store data using JSON file



## 🛠️ Technologies Used

* 🐍 Python
* 📄 JSON (for data storage)



## ▶️ How to Run

### 1. Clone the Repository

### 2. Run the Program

```bash
python expense_tracker.py
```
